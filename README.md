# Help Me Decide: Real Estate Edition

Help Me Decide is an AI-assisted real estate decision platform designed to help homebuyers compare properties based on what actually matters to them.

Instead of simply filtering homes by price, bedrooms, or location, the system will evaluate properties against a buyer's personal priorities, financial considerations, commute preferences, property characteristics, and other tradeoffs.

## Project Goal

The goal is to build a system that can answer questions such as:

- Which property is the best overall fit for this buyer?
- Why does one property rank higher than another?
- What tradeoffs is the buyer making?
- Are there important details the buyer may be overlooking?
- How do monthly costs, commute times, taxes, and property features affect the decision?

The project will begin as a simple Python application and gradually evolve into a production-style AI application.

## Version 1

Version 1 will allow a user to:

- Create a buyer profile
- Define buyer priorities
- Add properties manually
- Compare properties
- Calculate weighted property scores
- Rank properties from best fit to worst fit
- Explain why each property received its score

## Planned Architecture

Future versions will introduce additional technologies as the project grows.

Planned technologies include:

- Python
- SQL / PostgreSQL
- FastAPI
- REST APIs
- OpenAI or other LLM APIs
- Structured AI outputs
- Embeddings
- Vector search
- Retrieval-Augmented Generation (RAG)
- AI tool calling
- Agent workflows
- Docker
- Cloud deployment
- Logging and monitoring
- AI evaluations
- Human-in-the-loop approval workflows

## Long-Term Vision

The long-term goal is to create an AI-powered property intelligence system that can combine:

- Buyer preferences
- Property information
- Estimated monthly costs
- Property taxes
- Commute times
- Flood information
- HOA information
- Property documents
- Inspection reports
- Seller disclosures
- Comparable sales
- Other relevant real estate data

The system should help buyers understand not only which property scores highest, but why.

Eventually, the platform will include a "What Am I Missing?" feature that analyzes a buyer's finalist properties and identifies overlooked tradeoffs, contradictions, risks, or factors that may affect the final decision.

## Why This Project Exists

Homebuyers often make decisions using dozens of competing factors that are difficult to compare objectively.

Help Me Decide is intended to combine deterministic software, real-world data, and artificial intelligence to create a more transparent and useful decision-making process.
